Overview
This is the backend for an auction application. It handles user authentication, auctions, bids, comments, and watchlists.

Features
* User registration and login
* Create, view, and close auctions
* Place bids and add comments
* Manage watchlists
* Filter auctions by category

 Models
* User – user accounts
* List_Auctions – auction listings
* Comment – auction comments
* Watchlist – user watchlists
* Watchlist_Items – items in watchlists
