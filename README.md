Overview : This is an auction website that allows users to register, create and view auctions, place bids, add comments, manage watchlists, and filter auctions by category.

Features
* User registration and login
* Create, view, and close auctions
* Place bids and add comments
* Manage watchlists
* Filter auctions by category

 Models
* User – user accounts
* List_Auctions – auction listings
* Comment – auction comments
* Watchlist – user watchlists
* Watchlist_Items – items in watchlists

Project Status
Backend is complete and functional
Frontend is still in progress
